# Gary

A crew chief for iRacing and Le Mans Ultimate. He watches your telemetry and tells you the
things you'd otherwise be reading off an overlay — lap times, fuel, gaps, flags, incidents, and
the whole pit sequence — and answers when you ask him things.

**This is an alpha.** It works, it's in daily use, and it will still get things wrong.

📖 **[Full documentation](https://dgutierrez1287.github.io/gary-releases/)** — install steps,
every voice command, settings reference, and what actually works today.
